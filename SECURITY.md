# Política de segurança

## Relato responsável

Não publique detalhes de uma vulnerabilidade em issue pública. Envie um relato
privado ao mantenedor do repositório, com:

- descrição do problema e impacto;
- versão afetada;
- passos mínimos para reproduzir;
- sugestão de correção, se disponível.

Não envie senhas, tokens ou dados pessoais no relato.

## Escopo

Esta política cobre o código do TubeSlice e seus scripts de empacotamento.
Vulnerabilidades no YouTube, no FFmpeg, no Python ou em dependências externas
devem ser encaminhadas aos respectivos projetos.
